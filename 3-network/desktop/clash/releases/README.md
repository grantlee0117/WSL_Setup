# Clash Verge 安装包

各平台安装包都在这（Win / macOS / Linux，按架构分目录），直接用。

> 版本说明：normal 版（Win/macOS/Linux 主流架构）为 **2.2.3**，WebView2 修复版与 ARMv7 为 **2.4.3**；功能一致，按你的系统取用即可。

只有 Windows 的 WebView2 修复版（`win/WebView2_Bundled/`，160+ MB）超过 GitHub 单文件上限没入库——系统缺 WebView2 运行时才需要它，去官网下：
https://github.com/clash-verge-rev/clash-verge-rev/releases
