# Windows 新电脑配置指南

> **适用场景**：拿到一台全新电脑（或重装系统后），从零配置 Windows 11 开发环境。
>
> **预估耗时**：30-60 分钟（取决于下载速度）。

---

## 一、获取纯净的 Windows 系统

大多数人的电脑用久了都会积累各种问题（捆绑软件、系统垃圾、驱动冲突等）。开始配置开发环境前，建议先确保系统足够纯净。根据你的实际情况，选择对应的方案：

### 情况一：新电脑 / 电脑本身没问题

新电脑出厂一般已预装好系统，或者你的电脑本身运行正常。这种情况下，检查一下系统是否足够纯净（没有大量捆绑软件、流氓软件等）。如果不够纯净，使用系统自带的重置功能恢复：

1. 按 `Win + I` 打开**设置**
2. 左侧选择**系统** → 右侧点击**恢复**
3. 找到"重置此电脑"，点击**初始化电脑**
4. 选择**删除所有内容**
5. 选择**云下载**（会从微软服务器下载最新镜像，比本地恢复更干净）

> **说明**：云下载需要联网，耗时取决于网速。重置后会获得一个干净的 Windows 11 系统，无任何捆绑软件。

### 情况二：电脑本身存在问题

如果你的电脑已经有比较严重的问题（频繁蓝屏、系统损坏、中毒严重等），系统自带重置可能都不靠谱。这种情况推荐**先找专业服务重装系统**：

1. 淘宝搜索"远程重装系统"，约 30 元，让店家装一个 Windows 11 专业版——专业的事交给专业的人，省心省力
2. 重装完成后，再用上面情况一的**系统重置**操作一次，获得彻底纯净的系统

> **为什么重装后还要再重置？** 淘宝重装的系统可能自带捆绑软件，再重置一次可以确保系统完全干净。

### 重置后的首次开机设置（OOBE）

系统重置/重装完成后会重启进入「开箱体验」（OOBE）。其中**地区、时区、语言/键盘**是三个个性化选择——没有标准答案（但地区推荐美区），下面把利弊讲清楚，你按自己的使用场景选（这几项进桌面后都能随时改）。

**① 国家/地区**

影响 Microsoft Store 应用可用性、Windows AI（Copilot 等）开放程度、Edge/Bing 默认内容。

| 选择 | 利 | 弊 |
|------|----|----|
| 美国 | Store 应用最全、AI 功能开放最多、内容限制最少，对 AI 工具和软件最友好 | 无 |
| 中国 |无 | 部分 Store 应用 / AI 功能受限 |

**② 时区**

决定系统时间对应哪个地区——**看你想要什么，并不是必须跟所在地时区一致**。系统时间会体现在日志时间戳、git 提交时间、计划任务、文件时间上。

- **1. 选择实际所在地时区**（国内即 UTC+8）：本地看时间最直观。
- **2. 选择远程服务器 / 协作团队 / VPN 出口地区时区**：与服务器统一时区，跨时区协作和对日志更省心。

> 地区选美区**不会**强制时区，时区可独立设置、随时可改。

**③ 语言 / 键盘**

| 选择 | 利 | 弊 |
|------|----|----|
| 中文界面 | 上手快、界面友好 | — |
| 英文界面 | 报错信息可直接搜英文资料、与国际教程/截图一致、AI 读取英文系统信息更准 | 初期界面不熟悉 |

> 键盘布局：美式（开发者主流、符号位置标准）或中文（按习惯）。语言和键盘随时可加可换。

**④ 账户：本地账户 vs 微软账户（按需选）**

Windows 11 的 OOBE 默认强制联网并登录微软账户。如果你想要一个不绑微软账户的干净本地管理员账户，在「让我们为你连接网络」这一步按 `Shift + F10` 调出命令提示符，📋 执行：

```
start ms-cxh:localonly
```

回车后会弹出本地账户创建界面。若该命令在你的版本无效，改用旧版写法 `OOBE\BYPASSNRO`（回车后机器自动重启，重走 OOBE 时选「我没有 Internet 连接」即可继续）。

两种账户各有取舍：

- **本地账户**：不绑微软、重装更干净，不会触发 BitLocker 自动加密（见下方提示），适合开发机。
- **微软账户**：OneDrive 同步、跨设备设置漫游等全家桶功能开箱即用；代价是 24H2 起会自动开启 BitLocker 设备加密。

> ⚠️ **BitLocker 提示（微软账户用户必看）**：Windows 11 24H2 用微软账户登录会**自动开启 BitLocker 设备加密**。加密本身没问题，但若恢复密钥丢失（换主板/清 TPM/重装后无法解密），数据会永久锁死。请在 `设置 → 隐私和安全性 → 设备加密` 中确认状态，并提前将恢复密钥备份到微软账户或记录在安全位置。

**⑤ 隐私设置**

OOBE 末尾那一串隐私开关（诊断数据、查找我的设备、位置、定向广告、手写和键入改进等）对开发机基本无用，按需关闭，一般全关更干净、遥测更少。Cortana、OneDrive 自动备份、手机链接等提示也可按需跳过。

## 二、显示器设置

按 `Win + I` → **系统** → **屏幕**。

**单显示器**：设置合适的分辨率和缩放比例即可。

**多显示器**：

1. 选择**扩展这些显示器**（两个屏幕各显示不同内容）
2. 拖动显示器图标调整排列顺序（左右位置要和实际摆放一致）
3. 点击你想作为主屏的显示器，勾选**设为主显示器**
4. 分别点击每个显示器，单独设置其分辨率和缩放比例

> **提示**：每个显示器可以独立配置分辨率和缩放比例。比如笔记本屏幕用 150% 缩放，外接显示器用 100% 缩放。注意要使用系统预设的缩放选项（100%、125%、150% 等），不要用自定义缩放——自定义缩放会强制所有显示器使用同一个比例。

## 三、NVIDIA 显卡设置（有 NVIDIA 显卡才需要）

桌面空白处**右键** → **显示更多选项** → **NVIDIA 控制面板**。

### 3.1 图像质量

左侧选择**通过预览调整图像设置** → 选择**使用我的优先选择，侧重于**：拖到**质量**一端。

### 3.2 首选图形处理器

左侧选择**管理 3D 设置** → **全局设置**：

- **首选图形处理器**：从"自动选择"改为**高性能 NVIDIA 处理器**
- 下方设置列表中找到**电源管理模式**：改为**最高性能优先**

> **说明**：新版 NVIDIA 控制面板中会提示"Windows 操作系统现在管理图形处理器的选择"，你也可以通过 Windows 设置 → 系统 → 屏幕 → 图形 来管理各应用使用哪个 GPU。在 NVIDIA 控制面板中设置为高性能处理器仍然有效，作为全局默认值。
>
> 另外，管理 3D 设置中还有一个**程序设置**选项卡，如果你希望某些特定程序一定使用独显优化，可以在那里单独配置。

### 3.3 PhysX 配置

左侧选择**配置 Surround、PhysX** → **PhysX 设置**：

- 处理器选择你的独立显卡（如 `NVIDIA GeForce RTX 5060 Laptop GPU`）

> **说明**：以上设置让系统默认使用独立显卡而非集成显卡，提升图形性能。笔记本用户注意这会增加功耗和发热。如果你的 NVIDIA 控制面板界面和上述描述不完全一致，属正常现象——不同驱动版本界面会有差异，找到对应功能设置即可。

## 四、关闭 UAC 弹窗（可选）

UAC（用户账户控制）会在安装软件、修改系统设置时弹出确认窗口。开发场景下频繁弹出较烦，可以关闭。

1. 按 `Win` 键，搜索 **UAC**
2. 点击**更改用户账户控制设置**
3. 滑块拖到最底部**从不通知**
4. 点击**确定**

> **注意**：关闭 UAC 会降低系统安全性。如果你的电脑会接触不可信的软件或网站，建议保持默认。

## 五、安装基础软件

以下是开发环境的基础软件，**安装顺序很重要**——刚重置完的系统没有代理，也没有好用的浏览器，所以需要按下面的顺序逐步搭建起来。

### 5.1 微信

下载安装 [微信 for Windows](https://weixin.qq.com/)。

> **为什么先装微信？** 刚重置完的电脑什么都没有，微信是最方便的文件传输通道——手机上的配置文件、订阅链接、安装包等都可以通过微信直接传到电脑上。也可以找朋友帮忙发文件。

### 5.2 VSCode

下载安装 [Visual Studio Code](https://code.visualstudio.com/)。

安装时建议勾选：

- **将"通过 Code 打开"操作添加到 Windows 资源管理器文件上下文菜单**
- **将"通过 Code 打开"操作添加到 Windows 资源管理器目录上下文菜单**
- **将 Code 注册为受支持的文件类型的编辑器**
- **添加到 PATH**

> **为什么这么早装 VSCode？** 这个项目面向的是开发者，通过微信或 U 盘传过来的各种配置文件、代码片段需要一个好用的编辑器来查看和编辑，所以紧接着就装 VSCode。
>
> 安装完成后，在 VSCode 的扩展商店中搜索并安装 **WSL** 扩展（由 Microsoft 发布），后续配置 WSL 时会用到。

### 5.3 代理工具（如需科学上网）

安装 [Clash Verge Rev](https://github.com/clash-verge-rev/clash-verge-rev/releases) 或你习惯的代理工具。

> **重要**：后续很多开发工具的下载和使用都依赖网络畅通。如果你的网络环境需要代理，务必先装好代理工具。安装包和订阅链接可以通过微信从手机传过来。
>
> **安装之后的配置**（订阅、节点、TUN 模式、配置文件、网络排错）统一见 [2-network](../2-network/README.md)。本节只负责把软件装上。

### 5.4 浏览器

下载安装 [Google Chrome](https://www.google.com/chrome/)。

> 有了代理之后就可以顺畅访问 Google 了。如果暂时没有代理，可以先用 Edge 浏览器下载。

### 5.5 Git

下载安装 [Git for Windows](https://git-scm.com/download/win)。

> 嫌官网下载慢或想看图文步骤，本目录附带了一份离线安装教程：[`git安装教程.pdf`](./git安装教程.pdf)。

安装完成后打开 **Git Bash**（不是 PowerShell），配置用户信息：

```bash
git config --global user.name "你的名字"
git config --global user.email "你的邮箱"
git config --global core.autocrlf input
```

> **说明**：`core.autocrlf=input` 确保提交代码时将 Windows 的 CRLF 换行符转换为 LF，避免跨平台换行符问题。

### 5.6 配置 SSH Key

仍然在 Git Bash 中，生成密钥对：

```bash
ssh-keygen -t ed25519 -C "你的邮箱"
```

- 路径：直接回车（使用默认路径 `~/.ssh/id_ed25519`）
- 密码：直接回车（不设密码），或设一个自己记得住的

查看公钥并复制：

```bash
cat ~/.ssh/id_ed25519.pub
```

输出类似 `ssh-ed25519 AAAA......` 的一长串字符串，**完整复制**。

去 GitHub → **Settings** → **SSH and GPG keys** → **New SSH key**：

- **Title**：填一个能区分的名字，如 `Windows-我的电脑`
- **Key type**：选 `Authentication Key`
- **Key**：粘贴刚才复制的公钥

验证连接：

```bash
ssh -T git@github.com
```

首次连接会提示 `Are you sure you want to continue connecting`，输入 **yes** 回车。看到 `Hi xxx! You've successfully authenticated` 即成功。

> **SSH Key 是什么**：可以理解为一把"钥匙"（私钥，留在电脑上）和一把"锁"（公钥，放到 GitHub 上）。有了这对钥匙和锁，你的电脑就可以免密码和 GitHub 通信。每台电脑各生成一对，把公钥都加到 GitHub 即可。**私钥永远不要发给别人。**

## 七、Deskflow 双机键鼠共享配置（可选）

> 如果你只有一台电脑，跳过本节。涉及静态 IP 和 VPN 的场景本人并未实测，不确定是否可行，仅供参考。

### 概述

Deskflow 是一款开源的键鼠共享工具（Synergy/Barrier 的分支），可以让两台电脑共用一套键盘鼠标，鼠标滑到哪台电脑屏幕上，键盘就自动控制哪台电脑，体验类似双显示器。

### 前提条件

- 两台电脑都已安装 Deskflow
- 两台电脑处于同一局域网
- 知道服务端电脑的局域网 IP（通过 `ipconfig` 查看）

### 配置步骤

#### 第一步：确定角色

选择一台电脑作为 **服务端（Server）**——共享键盘鼠标的那台，另一台作为 **客户端（Client）**。

> 简单理解：键盘鼠标插在哪台电脑上，哪台就是服务端。

#### 第二步：设置静态 IP（推荐）

公司多人共用网络时，DHCP 自动分配的 IP 可能频繁变动或冲突，导致 Deskflow 断连。建议两台电脑都设置静态 IP，一劳永逸。

**IP 分配方案：**

| 角色 | 静态 IP |
|------|---------|
| 服务端 | `192.168.1.200` |
| 客户端 | `192.168.1.201` |

> 选 200 以上是为了避开路由器 DHCP 自动分配范围（一般在 100 以内），减少 IP 冲突的可能。

**设置方法（两台电脑都要操作）：**

1. 按 `Win+R`，输入 `ncpa.cpl` 回车
2. 右键正在使用的网络适配器 → **属性**
3. 双击 **Internet 协议版本 4 (TCP/IPv4)**
4. 选 **使用下面的 IP 地址**，填入：

| 项目 | 值 |
|------|------|
| IP 地址 | `192.168.1.200`（服务端）或 `192.168.1.201`（客户端） |
| 子网掩码 | `255.255.255.0` |
| 默认网关 | `192.168.1.1` |
| 首选 DNS | `223.5.5.5` |
| 备用 DNS | `114.114.114.114` |

5. 点确定保存

> **注意**：
> - 如果公司换了路由器或网段变了（如从 `192.168.1.x` 变成 `192.168.0.x`），需要重新修改静态 IP
> - 确保选的 IP 没有被其他同事占用，可以先 `ping 192.168.1.200` 确认无人使用（ping 不通说明没人用）

#### 第三步：服务端配置

1. 打开 Deskflow
2. 选择 **"使用此计算机的键盘和鼠标（将此计算机设为服务器）"**
3. 点击 **"配置服务器(C)"**
4. 在**计算机**选项卡的屏幕布局网格中，将客户端电脑图标拖到服务端旁边（根据物理摆放位置放在左边或右边）
5. 双击新添加的屏幕图标，填入客户端电脑的 **屏幕名称**（即客户端 Deskflow 界面上显示的"此计算机名称"）
6. 确认后点击 **启动**

> **屏幕名称必须与客户端实际名称完全一致，否则无法连接。**

#### 第四步：客户端配置

1. 打开 Deskflow
2. 选择 **"使用另一台计算机的鼠标和键盘（将此计算机设为客户端）"**
3. 在服务器 IP 栏填入服务端的静态 IP：**`192.168.1.200`**
4. 点击 **启动**

#### 第五步：接受指纹验证

首次连接时，客户端会弹出 TLS 指纹验证提示，用于确认连接的是正确的服务端。直接点击 **接受/信任** 即可。

#### 第六步：防火墙放行

在服务端电脑上，用管理员权限打开 PowerShell，执行：

```powershell
New-NetFirewallRule -DisplayName "Deskflow" -Direction Inbound -Protocol TCP -LocalPort 24800 -Action Allow
```

这条命令放行 Deskflow 使用的 TCP 24800 端口。如果客户端也连不上，客户端也执行一次同样的命令。

#### 第七步：开机自启

1. 在桌面找到 Deskflow 的快捷方式（没有的话先创建一个）
2. 复制该快捷方式
3. 按 `Win+R`，输入 `shell:startup` 回车，打开启动文件夹
4. 将快捷方式粘贴到启动文件夹中

> 两台电脑都需要操作。

### 常见问题排查

#### 连接不上怎么办？

按以下顺序排查：

1. **确认 IP 是否正常获取**：多人共用网络或网卡驱动老化时，可能没分到 DHCP 的 IP（如显示 `169.254.x.x` 的随机地址），即使同一局域网也会连不上。用 `ipconfig` 检查，如果 IP 异常，依次执行：
   ```powershell
   ipconfig /release
   ipconfig /renew
   ```
   重新获取正常 IP 后再尝试连接。
2. **检查网络连通性**：在客户端 PowerShell 中执行 `ping <服务端IP>`，如果 ping 不通说明网络层有问题
3. **关闭代理/VPN（梯子）**：代理软件会改变网络路由，导致局域网设备无法直接通信。解决方法有两个——直接关闭代理，或在代理软件中将 `192.168.*.*` 加入直连/绕过列表
4. **防火墙放行**：确认服务端已放行 TCP 24800 端口
5. **屏幕名称检查**：确认服务端配置中填写的客户端屏幕名称与客户端实际名称完全一致
6. **重启 Deskflow**：两边都点停止再启动

#### 鼠标在屏幕角落误触发切换？

在服务端 → 配置服务器 → **高级** 选项卡 → **屏幕死角** 中，勾选对应的角落（左上、左下、右上、右下），勾选后鼠标在该角落不会触发切换。

### 可选优化

#### 快捷键切屏

在服务端 → 配置服务器 → **热键** 选项卡中：

1. 左侧"热键"点 **+ 新建(N)**，按下想要的快捷键组合（如 `Ctrl+Alt+→`）
2. 右侧"动作"点 **+ 新建(W)**，选择 `switchToScreen`，指定目标电脑
3. 点确定保存

#### 剪贴板共享

默认已开启（高级选项卡中"启用剪贴板共享"），可以在一台电脑复制文字/图片，另一台直接粘贴。默认限制 3MB 偏小，建议改成 **30MB**，足够应对截图和大段内容。

#### 全屏游戏防误触

玩全屏游戏（如无畏契约）时，鼠标滑到屏幕边缘可能误切到另一台电脑。解决方法：按 **Scroll Lock** 键锁定鼠标到当前电脑，再按一次解锁。如果键盘没有 Scroll Lock 键，可以在热键选项卡中自定义一个快捷键，动作选 `lockCursorToScreen`。

#### 高级选项卡其他设置说明

| 设置项 | 说明 | 建议 |
|--------|------|------|
| 剪贴板共享 | 跨电脑复制粘贴 | 保持开启，限制改为 30MB |
| 屏幕死角 | 防止角落误触发切换 | 按需勾选 |
| 网络协议 | Synergy / Barrier | 保持默认 Barrier |
| 等待后切换 | 鼠标到边缘后延迟切换 | 误触多的话可以开启 |
